#TROGDOR!!!: The Board Game: The Terminal Game
Burninate a countryside with *only* the finest of NCurses ASCII text, all on your Linux terminal of choice.

#Game Instruction
Upon starting a new game, the non-moving actions can be found in a menu below the board, scroll through the options with the arrow keys. Movement is controlled with the number pad

[Info on game mechanics can be found in the PDF file for the board game.](https://trogdorboardgame.homestarrunner.com/Trogdor_Rulebook.pdf)

#Bulding
A simple `make` in the project directory should be able to handle the whole thing.

If you also want the board editor, compile the relevant C file seperately.
